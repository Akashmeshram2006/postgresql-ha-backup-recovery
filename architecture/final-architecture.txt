============================================================
LAB ENVIRONMENT
============================================================

The project uses Docker containers to simulate
independent PostgreSQL and supporting infrastructure nodes.

This is a laboratory implementation of a multi-node
PostgreSQL HA architecture.


============================================================
IMPORTANT DISTINCTION
============================================================

Replication provides high availability and copies database
changes between nodes.

Backups provide an independent recovery mechanism.

Therefore:

Replication != Backup


============================================================
FAILURE SCENARIO
============================================================

Normal:

Client
  |
HAProxy
  |
PG1 PRIMARY
  |
  +---- PG2 REPLICA
  |
  +---- PG3 REPLICA


After PG1 failure:

PG1 = FAILED

Patroni coordinates failover.

One healthy replica can be promoted to PRIMARY.

HAProxy can then route client traffic to the new PRIMARY.
